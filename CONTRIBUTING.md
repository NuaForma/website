# Contribute to the website

Discuss changes through an issue and use a focused branch/PR against develop. Write English repository documentation, sign every commit and use Conventional Commits. Run the static/profile/ZIP, packaging, JavaScript/tab and relevant Compose checks in the root README. Explain documentation and Playground impact in each PR. Do not describe unexecuted rendering or client checks as passing.

Main is the live site. Normal updates use a checked PR; the maintainer may exceptionally push a small signed correction directly to main, then synchronize it back to develop through a PR. Do not force-push, delete protected branches or disable signature checks. Pages cannot deploy unless its own checks succeed. Product feature requests and runtime security changes belong in the [product issue tracker](https://github.com/NuaForma/NuaForma/issues).

Never submit confidential templates, private fonts, secrets or operator data. Preserve existing URLs, reviewed security profiles, notices and the separation of production and development kits. Product binaries and releases are not published here.
