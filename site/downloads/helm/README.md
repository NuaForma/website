# Native-engine Helm evaluation example

Candidate `0.5.0-alpha.1` uses RuntimeDefault seccomp with non-root execution, a read-only root, dropped capabilities and no privilege escalation. No custom host profiles or unprivileged-user-namespace setup is required. Preserve memory/CPU limits, bounded temporary storage and probes; configure pod PID bounds through your platform. This example does not qualify every Kubernetes cluster. Keep the service private and add authenticated TLS before remote access.

The chart pins reviewed published production index `sha256:9607e26886ee83608e3e1b8bc0a8c32d38dc23e48ea611f9bbb1f25795abcfab`. The development Playground index is `sha256:93cbf948538946d224b72b8880ec998f05ecf9d5e285eefea59bcb61ca09b0a7`. Use `helm lint ./nuaforma`, `helm template nuaforma ./nuaforma` and `helm upgrade --install nuaforma ./nuaforma`. The default node selector is native Linux/amd64; choose arm64 on ARM64 nodes. Preserve NOTICE/LICENSE, component source notices and the supplied security policies, and configure existing read-only font/extension PVCs.
