A release of its own.

Image Comparison has its own version, independent of the NuaForma document generator.

FIRST NUAFORMA RELEASE

5.0.0

Version 5.0.0 is the first NuaForma release, available on Maven Central for Java and Kotlin.

  • Java 17 minimum, with packages under dev.nuaforma.image.comparison.
  • Standalone Java core and an optional Kotlin assertion DSL.
  • Comparison of color and alpha, with differing-pixel percentages calculated over non-excluded pixels.
  • Detected regions stay inspectable even when drawing filters hide an outline.
  • Region traversal uses a heap worklist instead of recursive calls.

Migration from upstream: update imports and recompile. The Java runtime baseline, package names and approved comparison behavior differ from upstream 4.4.0. Review your tolerances and acceptance limits.

Two artifacts, one version

dev.nuaforma:image-comparison:5.0.0 is the Java core. Kotlin users declare only dev.nuaforma:image-comparison-kotlin:5.0.0; the core arrives transitively.
