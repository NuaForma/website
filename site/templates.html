WRITE YOUR TEMPLATE

Small markers.
Flexible documents.

Type these markers into your Word document. They use the fields inside your request's data object. Keep your styles, tables and images; let the template decide which content belongs in the result.

Fields and nested data

Read object members and list items. The data prefix is optional unless you need to refer explicitly to the root object.

Dear {customer.name},
Reference: {orders[0].reference}
City: {data["billing-address"]["city name"]}

Insert strings, numbers or booleans. An explicit null prints nothing; an object or list needs further selection or conversion.

If, else and inline conditions

Include a section, a paragraph or just a few words in the middle of a sentence. The else branch is optional.

This is {#if draft}a draft{#else}final{/if}.
{#if total >= 1000 && approved}
Additional review completed.
{/if}

Conditions must return a real boolean. A string is not automatically true because it contains text. For “else if”, nest another #if inside #else.

For each item

The for-loop syntax is #each. Give the current item an alias and repeat content for every element of a list.

{#each orders as order}
{loop.number}. {order.reference}
{/each}

An empty list produces nothing. loop provides index, number, size, first and last. DOCX also supports structural repetition of supported paragraphs and table rows.

Null, missing and string checks

Use ?? to supply an explicit fallback for missing or null fields. Empty strings remain empty unless you test them.

{customer.nickname ?? customer.name ?? "Guest"}
{#if (name ?? null) == null}No name supplied{/if}
{#if trim(name ?? "") == ""}Name is blank{/if}
{#if contains(note ?? "", "review", true)}Review requested{/if}

Built-ins: contains, startsWith, endsWith, trim and equalsIgnoreCase. The optional third boolean on substring/prefix/suffix checks enables case-insensitive matching. A direct name == null check requires the field to exist.

Format and chain value pipes

A pipe transforms a value before insertion. Built-in number and date formatting uses the generation's explicit locale and time zone.

{total | number("#,##0.00")}
{issuedOn | date("dd-MM-uuuu")}
{customer | select("balance") | number("0.00")}

select illustrates a custom value pipe, not a built-in: an operator must install it first. Registered pipes can accept arguments and return values for the next stage. Every stage needs parentheses. Pipes go on placeholders, not inside #if or #each expressions.

Insert an image

The DOCX generator's built-in content pipe turns a Base64 PNG or JPEG value into an inline image, for both DOCX and PDF generation.

{company.logo | image(40, 20, true)}
{optionalPhoto ?? null | image(25, 35, true)}

The first two arguments are maximum width and height in millimetres; true preserves the aspect ratio without upscaling. Defaults are image(50, 50, true). Null inserts nothing. Supply plain padded Base64, not a URL or data URI. Content pipes cannot be chained before or after any other pipe.

Yes, you can nest them

Put an if inside a loop, a loop inside an if, or another loop inside that loop. Use different aliases to keep outer items accessible.

In this example, only active projects appear. Only included tasks appear, and each task can conditionally show a review note. The inner loop.number belongs to the task list; after that loop, the enclosing loop is restored.

Each block must close with its matching {/if} or {/each}. Processing depth, repetitions and output remain bounded.

{#each projects as project}
{#if project.active}

Data inserted into the document stays literal: it cannot introduce new template instructions. Write {{ and }} in the template for literal braces. Markers do not automatically normalize whitespace or line breaks; use the DOCX structural rules when adding or removing whole paragraphs/rows. Text watermarks resolve text expressions and value pipes, but cannot contain image/content pipes.
